## Code of Conduct

This project adheres to a code of conduct that all contributors are expected to follow. Please be respectful and constructive in all interactions.

## How Can I Contribute?

### Reporting Bugs

Before creating a bug report, please:

1. **Check existing issues** to avoid duplicates
2. **Use the latest version** to ensure the bug hasn't been fixed
3. **Collect information** about the bug:
   - Steps to reproduce
   - Expected behavior
   - Actual behavior
   - Screenshots (if applicable)
   - Windows version
   - Qash Compass version

**Create a bug report** using the bug report template with:
- A clear, descriptive title
- Detailed steps to reproduce
- Any relevant logs or error messages
- Your system configuration

### Suggesting Features

Feature suggestions are welcome! Please:

1. **Check existing suggestions** to avoid duplicates
2. **Provide context** about the problem you're trying to solve
3. **Describe the proposed solution** in detail
4. **Explain the use case** and potential benefits
5. **Consider alternatives** you've thought about

### Improving Documentation

Documentation improvements are always appreciated:

- **Fix typos or clarify existing documentation**
- **Add examples or screenshots**
- **Improve installation instructions**
- **Create tutorials or guides**
- **Translate documentation** (if applicable)

## Documentation Contributions

Since this is a distribution repository (no source code), most contributions will be documentation-related:

### What You Can Contribute

1. **User Guides**: Tutorials, how-tos, best practices
2. **Screenshots**: Visual guides for features
3. **FAQ Updates**: Common questions and answers
4. **Troubleshooting**: Solutions to common problems
5. **Installation Guides**: Platform-specific instructions

### Documentation Standards

- Use clear, concise language
- Include screenshots where helpful
- Follow the existing documentation structure
- Test instructions before submitting
- Use proper Markdown formatting

## Pull Request Process

1. **Fork the repository** and create a branch from `main`
2. **Make your changes** following the guidelines above
3. **Test your changes** (especially for documentation)
4. **Update documentation** if needed
5. **Create a pull request** with:
   - Clear title describing the change
   - Detailed description of what and why
   - Reference to any related issues
   - Screenshots for visual changes

### Pull Request Guidelines

- Keep changes focused and atomic
- Write clear commit messages
- Ensure all links work correctly
- Check spelling and grammar
- Follow existing formatting conventions

## Review Process

- All contributions will be reviewed by maintainers
- Feedback will be provided constructively
- Changes may be requested before merging
- Once approved, changes will be merged to main

## Questions?

If you have questions about contributing:

- Open a [Discussion](https://github.com/Nze-Jerry/Qash-Compass/discussions)
- Create an [Issue](https://github.com/Nze-Jerry/Qash-Compass/issues)
- Review existing documentation

## Recognition

All contributors will be recognized in our documentation and release notes.

Thank you for helping make Qash Compass better! 🙏
