## 📋 Overview

Qash Compass is a powerful offline desktop application designed to help you manage your personal finances with ease. Built specifically for Windows, it provides a secure, private environment for tracking income, expenses, budgets, and financial goals without requiring an internet connection.

## ✨ Key Features

- **Offline-First**: All your financial data stays on your computer - no internet required
- **Privacy-Focused**: Your financial information never leaves your device
- **Budget Management**: Create and track budgets across multiple categories
- **Expense Tracking**: Log and categorize your daily expenses
- **Income Recording**: Track multiple income sources
- **Financial Reports**: Generate insightful reports and visualizations
- **Secure**: Local data storage with optional encryption
- **Multi-Currency Support**: Handle transactions in different currencies
- **Export Functionality**: Export your data to CSV/Excel for backup or analysis

## 💻 System Requirements

- **Operating System**: Windows 10 or later (64-bit)
- **RAM**: 4GB minimum, 8GB recommended
- **Storage**: 500MB available disk space
- **Display**: 1366x768 minimum resolution

## 📥 Download & Installation

### Latest Release

Download the latest version from the [Releases](https://github.com/Nze-Jerry/Qash-Compass/releases) page.

### Installation Steps

1. Download the installer (`QashCompass-Setup.exe`) from the latest release
2. Run the installer as Administrator
3. Follow the installation wizard prompts
4. Launch Qash Compass from the Start Menu or Desktop shortcut

For detailed installation instructions, see the [Installation Guide](docs/INSTALLATION.md).

## 🚀 Getting Started

1. **First Launch**: When you first open Qash Compass, you'll be guided through initial setup
2. **Create Your Profile**: Set up your financial profile and preferences
3. **Add Accounts**: Add your bank accounts, credit cards, and cash accounts
4. **Start Tracking**: Begin logging your income and expenses
5. **Set Budgets**: Create budgets for different spending categories

For a comprehensive guide, see the [User Guide](docs/USER_GUIDE.md).
