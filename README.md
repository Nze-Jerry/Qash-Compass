# Qash Compass 💰

**Qash Compass** is a private, offline personal finance desktop application for Windows.  
Track income, expenses, loans, budgets, and recurring transactions — without cloud accounts, subscriptions, or internet dependence.

## 🔐 Privacy First
- 🖥 100% **Offline Desktop App**
- 🔒 **No Cloud Storage**
- 🚫 **No Subscriptions**
- 📂 Data stored **locally on your PC**
- 🧠 Local-only usage counters (never sent anywhere)

Your financial data never leaves your computer.

## ✨ Key Features
- 📊 Dashboard with monthly insights
- 💸 Expense tracking with custom categories
- 💰 Income management
- 🤝 Loans (borrowed & lent) with balance tracking
- 📈 Reports & charts (monthly overview)
- 📂 Budget limits with smart alerts
- 🔄 Recurring transactions (salary, bills, subscriptions)
- 🛒 Shopping list with costs & reminders
- 👥 Multi-user login (ideal for shared PCs)
- 💾 Automatic local backups
- 📤 Export to Excel

## 🖥 Supported Platform

## ❓ FAQ

### Is my data safe?
Yes. All data is stored locally on your computer. No uploads, no sync, no tracking.

### Does it use the internet?
No. The Internet is only required for downloading or license activation.

### Is there a subscription?
No. Qash Compass is a one-time purchase.

### Can I use it on shared computers?
Yes. Supports multiple users with separate logins.
