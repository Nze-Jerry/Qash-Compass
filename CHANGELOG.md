# Changelog

All notable changes to Qash Compass will be documented in this file.

and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-11

### Added
- Initial release of Qash Compass
- Offline-first personal finance management
- Budget tracking and management
- Expense categorization and tracking
- Income recording across multiple sources
- Financial reports and visualizations
- Multi-currency support
- Data export to CSV/Excel
- Local data storage with optional encryption
- Windows 10+ support

### Security
- Local-only data storage for privacy
- Optional data encryption
- No telemetry or external connections
